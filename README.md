# PDF Master

브라우저에서 직접 실행되는 무료 PDF 편집 웹앱입니다. **파일이 서버로 전송되지 않습니다.** 모든 처리는 사용자의 브라우저 내부에서만 이루어집니다.

## 기능

| 기능 | 설명 |
|------|------|
| **이미지 → PDF** | JPG, PNG, WEBP 이미지를 선택하여 PDF로 변환. 드래그로 순서 변경 |
| **PDF 병합** | 여러 PDF를 하나로 합치기. 드래그로 순서 변경 |
| **페이지 삭제** | 썸네일 클릭으로 삭제할 페이지를 선택하여 제거 |
| **페이지 재정렬** | 페이지 썸네일을 드래그하여 순서 변경 |
| **페이지 삽입** | 기존 PDF의 원하는 위치에 다른 PDF 삽입 |
| **페이지 추출** | 선택한 페이지 또는 범위를 새 PDF로 추출 |
| **PDF 분할** | 각 페이지별 또는 지정 범위별로 PDF 분할 |
| **페이지 회전** | 선택한 페이지를 90°, 180°, 270° 회전 |

## GitHub Pages 배포 방법

1. 이 저장소를 Fork하거나 직접 파일을 업로드합니다.
2. 저장소 **Settings → Pages**로 이동합니다.
3. Source를 `main` 브랜치의 `/` (root)로 설정합니다.
4. **Save**를 클릭하면 몇 초 후 `https://<username>.github.io/<repository>/` 에서 접근 가능합니다.

빌드 도구나 서버가 필요 없습니다. `index.html`, `style.css`, `app.js` 파일만 있으면 바로 실행됩니다.

## 파일 구조

```
/
├── index.html    # 앱 구조 및 HTML
├── style.css     # 스타일 (라이트/다크 모드 포함)
├── app.js        # 모든 기능 구현 (Vanilla JS)
└── README.md
```

## 사용 라이브러리

| 라이브러리 | 버전 | 용도 |
|-----------|------|------|
| [pdf-lib](https://pdf-lib.js.org/) | 1.17.1 | PDF 생성, 병합, 삭제, 회전, 분할 등 조작 |
| [PDF.js](https://mozilla.github.io/pdf.js/) | 3.11.174 | PDF 페이지를 캔버스로 렌더링하여 썸네일 생성 |

두 라이브러리 모두 CDN에서 로드되므로 별도 설치가 필요 없습니다.

## 개인정보 보호

- **파일은 서버로 전송되지 않습니다.** 모든 PDF 처리는 사용자의 브라우저 메모리 내에서만 이루어집니다.
- 업로드된 파일은 페이지를 새로고침하면 완전히 삭제됩니다.
- 외부 API 호출이 없습니다.
- 원본 파일은 절대 수정되지 않습니다. 모든 작업은 복사본 기준으로 수행됩니다.

## 브라우저 지원

최신 Chromium (Chrome, Edge), Firefox, Safari를 지원합니다.
